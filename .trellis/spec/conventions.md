# Conventions Spec

`.trellis/` 不替代现有规则体系，只补充复杂任务层。

## 规则来源

- 通用仓库规范：`AGENTS.md`
- Claude 入口：`CLAUDE.md`
- Cursor 自动规则：`.cursor/rules/`
- 详细技能：`.cursor/skills/` 与 `.agents/skills/`

## 在 Trellis 中记录什么

应该记录：

- 任务目标
- 范围与非目标
- 关键假设
- 当前决策
- 验证方式与验证结果
- 待办和阻塞项

不应该记录：

- 与现有规范重复的大段仓库说明
- 可以直接引用的技能正文
- 与具体任务无关的长期规则

## 任务粒度

只有满足以下任一条件时，建议创建 Trellis 任务：

- 涉及多个子系统
- 预计跨多个会话
- 需要显式 PRD / 验收标准
- 需要把研究、实现、验证拆开记录
