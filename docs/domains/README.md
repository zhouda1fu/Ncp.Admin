# 领域文档索引（平台脚手架）

> 当前仓库仅保留 IAM + 工作流相关领域文档。扩展新业务模块时，可在此目录下新增子文件夹。

| 领域 | 说明 | 入口 |
| --- | --- | --- |
| 用户 | 账号、角色/部门/岗位绑定、导入导出、创建用户审批 | [`user/README.md`](./user/README.md) |
| 工作流 | 流程定义、实例流转、任务审批、业务适配器扩展 | [`workflow/README.md`](./workflow/README.md) |

每个领域目录通常包含：

| 文件 | 用途 |
| --- | --- |
| `README.md` | 模块职责与阅读顺序 |
| `flows.md` | 业务流程与状态流转 |
| `api.md` | 接口与权限契约 |
| `dependencies.md` | 跨模块依赖与风险 |
